# dam-mac

Public **release binaries** for [DAAAM](https://daaam.media) (macOS Apple Silicon).

Source code lives in a private repo. This repository only hosts GitHub Releases:

- `DAAAM_<version>_aarch64.dmg` — notarized installer
- `latest.json` — Phase A update manifest (Settings → About → Check for updates)

Stable manifest URL (baked into builds):

```
https://github.com/MunasheChitima/dam-mac/releases/latest/download/latest.json
```

Do not put secrets or source here.
