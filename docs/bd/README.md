# Canva/Pexels BD package

This folder packages the Canva/Pexels business development strategy into
concrete working documents.

## Contents

- [01-positioning.md](01-positioning.md): the sharpest product positioning and
  the primary wedge
- [02-target-accounts.md](02-target-accounts.md): buyer map, account priorities,
  and outreach order
- [03-pilot-proposal.md](03-pilot-proposal.md): recommended proof structure and
  success metrics
- [04-outreach-assets.md](04-outreach-assets.md): buyer-specific outreach copy,
  deck outline, and objection handling

## Recommended order of use

1. Use the positioning memo to align on the one-line description and the
   retrieval-before-generation thesis.
2. Use the target account map to identify named buyers inside Canva first and
   Pexels second.
3. Use the pilot proposal as the call to action for first outreach.
4. Use the outreach assets to tailor the message to enterprise, AI, or strategy
   buyers.
