# Canva/Pexels BD package

This folder packages the Canva/Pexels business development strategy into
concrete working documents.

The stance throughout is the same: the product was naturally heading into
Canva and Pexels's market. We would rather give them that value directly
than compete with them for it. This is not a plugin pitch.

## Contents

- [01-positioning.md](01-positioning.md): the product overlap, the offer, and
  the language to use
- [02-target-accounts.md](02-target-accounts.md): buyer map, account
  priorities, and outreach order
- [03-pilot-proposal.md](03-pilot-proposal.md): how to show the product, not
  how to plug it in
- [04-outreach-assets.md](04-outreach-assets.md): buyer-specific outreach,
  deck outline, and objection handling

## Recommended order of use

1. Use the positioning memo to lock the overlap story: this was heading into
   their market, so we would rather they have the value.
2. Use the target account map to start with Canva enterprise, corp dev, and
   AI product, then Pexels.
3. Use the product proof as the ask: show what we built, on their terms.
4. Use the outreach assets to tailor that story to each buyer.
