# Canva/Pexels BD package

This folder packages the Canva/Pexels business development strategy for
**dam-mac only**.

## Important product boundary

- **dam-mac**: DAM product with a custom visual indexing engine for image and
  content libraries; productized on Mac first, but not limited to Mac as a
  capability
- **FindandSeek**: separate product. Do not use it in this pitch.

If a document mentions document memory, agent file search, or local assistant
memory, it is the wrong product context.

For the explicit guardrail, see [product-boundary.md](product-boundary.md).

## Recommended order of use

1. Read the positioning memo and keep the pitch on visual DAM only.
2. Use the target account map to start with Canva enterprise, corp dev, and AI
   product leaders.
3. Use the product proof as the ask: show dam-mac on a representative visual
   corpus.
4. Use the outreach assets to tailor the message by buyer type.
